ABC → FolkFriend JSON

Select ABC files or paste ABC text. Conversion runs locally in this browser; this page does not call update.php. You can optionally load an existing FolkFriend JSON file. Existing entries in the new format are kept.

Contour encoding: MIDI 48–95 is encoded using abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUV. Each character represents one quaver (eighth note).
Processing: For tunes with multiple voices, the first declared voice is used. K:none is treated as K:C. If the melody is outside MIDI 48–95, it is shifted by octaves where possible. Chords are represented by their highest note. Broken rhythm can also follow rests. Tunes with fewer than four detected measures are skipped. Tunes without an I: field are also skipped. The value from I: is used as the key for the tune entry.
